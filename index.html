    Sync Grim Dawn

    Your files are safe. Read-only, nothing is uploaded, nothing is changed. How it works
    • Read-only. The site only asks your browser for permission to view files. Your browser enforces that, so nothing can be changed, moved, overwritten or deleted.
    • Nothing leaves your computer. There is no server behind this site. Files are read right here in this page and never uploaded, sent or shared with anyone, including whoever runs the site.
    • Only what's needed is read. Each character's player.gdc, plus the game's item database and English text for gear names. Everything else is ignored.
    • Kept in your browser only. Your progress, a small copy of each character file and the game's item data stay in this browser so you don't have to pick them again. Clearing your browser data removes them.
    • You stay in control. “Forget” buttons below remove saved data, and your browser's site settings remove the site's access.

    Your browser may ask something like “Let this site view files?” or call it “uploading”. Both are the read-only access described above.

    GrimTracker app

    Updates live while you play, Steam Cloud saves included. “Automatic” uses whichever save folder you played most recently.

    Game folder
    Your progress and Hall of the Fallen are saved on this PC, with a backup each day, so clearing browser data can't erase them.

    1Your characters

    Documents\My Games\Grim Dawn\save. Stays synced while you play.

    Steam\userdata\<id>\219990\remote\save. Read on each sync (browsers block live access to Program Files).

    1. The path is copied. In the folder window, click the address bar, press Ctrl+V, then Enter.
    2. Open your numbered Steam ID folder, then 219990, then remote.
    3. Click the save folder once, then Select Folder (or Upload). The files stay on your computer.

    Steam Cloud saves on Windows? The GrimTracker app reads them live, with no re-syncing. Download for Windows

    Chrome wouldn't connect that folder? If it said the folder "contains system files", Steam is installed inside Program Files, and Chrome blocks live sync there. You can still load a snapshot of your saves. You'll just need to click Sync again after you play. For automatic updates, use the GrimTracker app for Windows.

    2Gear data one time

    Pick your Grim Dawn install folder (the one with Grim Dawn.exe), usually C:\Program Files (x86)\Steam\steamapps\common\Grim Dawn

    The item database and English text (about 185 MB) are kept in this browser, so you only do this once. Do it again after a big game update.
